# VENTRA · Game Design v2 — Kesir Köprüsü

**Durum:** Tasarım konsepti kullanıcı tarafından onaylandı; **vertical slice henüz geliştirilmedi veya kabul edilmedi.**  
**Tarih:** 28.10.2026  
**Kapsam:** İlk olarak 4. sınıf Matematik / Birim kesir karşılaştırma / Tek oynanabilir bölüm.

## Bu paketin amacı

Game design kararlarını, ekran akışını, görsel hedefi ve doğrulama kriterlerini **Codex'e devretmeden önce** yazılı şekilde sabitlemek. Codex'in görevi bunlara göre geliştirmek ve açık bir uyumsuzluk raporu vermek; ürün tasarımını kendiliğinden yeniden tanımlamak değil.

## Dosyalar

- `01-GDD-V2.md`: Oyun kuralları, eğitsel hedef, ilk bölüm, hata/başarı tepkileri.
- `02-PLAYER-FLOW-AND-WIREFRAMES.md`: Mermaid diyagramı, ekranlar, mobil/masaüstü yerleşimleri.
- `03-ART-AND-UX-SPEC.md`: Tasarım sistemi, asset listesi, animasyon ve çocuk dostu UX.
- `04-TECH-AND-ACCEPTANCE.md`: Mevcut stack entegrasyonu, testler, kabul kapıları, MB bütçesi.
- `05-CODEX-IMPLEMENTATION-BRIEF.md`: Geliştiriciye verilecek uygulanabilir talimatlar.
- `DECISION-REGISTER.md`: Onaylı kararlar, tasarım varsayımları ve kapsam dışı işler.
- `references/kesir-koprusu-concept-reference.png`: Kullanıcının beğendiği örnek konsept görseli. **Bu bir sprite/oyun asset'i değildir.**
